# 快圖 · QuickPic Gallery Mod II

[English](README.en.md)

快圖是由 Jason Chen 維護的 Android 圖片瀏覽器，延續 [WSTxda 的 QuickPic Gallery Mod](https://github.com/WSTxda/QP-Gallery-Releases)，加入適合閱讀器、電子墨水螢幕和新版 Android 裝置的看圖操作。手機和平板都可以使用，安裝後的名稱為「快圖」。

## 本專案的功能

### 閱讀器與電子墨水螢幕

- 圖片轉場可選「無」，首次安裝的投影片也預設無轉場，減少看圖時的畫面變化。
- 設定 → 檢視 → 圖片中的「閱讀器模式」會保留舊頁，等下一張完整圖片載入好才換頁，不顯示模糊預覽或載入字樣。這會減少閃爍，但是延遲肯定會提高。預設關閉。
- 在「設定 → 檢視 → 操作 → 點擊翻頁」選擇下方兩角、左右兩側、上下、單側上下或中間兩側的配置，並查看區域示意圖。首次安裝與舊版升級均預設停用，需手動啟用。中央區域可開關選單；滑動、雙擊及縮放保留原有操作。
- 可直接編輯包含或排除的資料夾路徑，決定要瀏覽哪些位置的圖片。
- 開啟 App 時預設顯示隱藏項目；已設定的隱藏項目密碼保護照常生效。

### 投影片與播放間隔

看圖時可以直接開始投影片播放。手機與平板工具列都提供播放和「投影片間隔」；刪除、編輯與分享放在三點選單。

首次安裝時，每張圖片預設停留 3 秒。「投影片間隔」會開啟浮動視窗，提供 3、5、10、30、60 秒及自訂秒數，讓你直接調整每張圖片停留的時間。自訂可設 1～86400 秒，輸入欄會保留上次套用的自訂值，切換常用秒數不會覆寫它。點「自訂」會直接套用記住的秒數；要改成新的秒數，輸入後按「套用自訂」即可。投影片使用目前開啟的圖片清單，也保留順序或隨機播放的選擇。

### 資料夾掃描與日期排序

掃描時先探索新加入或最近變動的資料夾，再補查已知路徑，讓新下載的漫畫能優先被找到。排序可分別選擇建立日期（加入時間）或修改日期。既有檔案若缺少可靠建立時間，初次會以修改時間建立基準；之後新增的項目會記住首次加入時間。

### 刪除圖片與資料夾

選擇刪除資料夾時，快圖會刪掉整個目錄，包含非圖片檔、隱藏檔與子資料夾。記憶卡需要先授予該位置的存取權；刪除失敗或取消時，尚未刪除的項目會保留在清單中。成功刪除父資料夾後，其子相簿也會一併移除。

單張和多選圖片會依本機／記憶卡的可用權限及媒體紀錄選擇刪除方式，減少重複清理與等待。保留逐張進度，完成後不再顯示診斷報告。

### 螢幕保護圖片

開啟圖片後，在三點選單選「設為」。快圖提供以下屏保操作：

| 選項 | 用途 |
| --- | --- |
| 設置為屏保 | 產生 PNG，直接顯示 Android 的 App 選擇器，讓你選擇開啟圖片的 App。最後的屏保設定由所選 App 或裝置系統完成。 |
| 設置為 B1051C 屏保 | 使用 B1051C 4.8.8／4.9.0 對應的原廠屏保元件，將目前圖片轉為 1860 × 2480 PNG，再交給系統套用。 |
| 設置為文石屏保 | 將目前圖片交給文石原廠屏保服務。需要相容的 BOOX 系統與原廠元件，一般 Android 手機不適用。 |

在「設定 → 檢視 → 圖片 → 顯示屏保選項」勾選想保留的項目，再按「儲存」。三個屏保選項可分別顯示或隱藏，也可全部隱藏；「桌布」仍會保留。按「取消」不更改設定。

乾淨首次安裝時，快圖只辨識一次裝置，選擇適合的預設選項；之後重開或更新不會重新辨識，也不會覆寫手動選擇。從舊版更新會保留原有選項，新增的文石選項預設隱藏，仍可手動開啟。

一般屏保 PNG 保存在 `QuickPic-Screensaver`。在「設定 → 檢視 → 圖片 → 設定屏保圖尺寸」可自訂寬高，或偵測目前螢幕的像素尺寸，再按「儲存」。圖片會從中央裁出符合目標長寬比的最大範圍，再縮放成指定尺寸。未設定時為 1860 × 2480；「恢復預設」可填回這組尺寸，儲存後生效。

直接設定入口會先準備獨立的圖片副本，原圖保留；確認前可取消。B1051C 的兩個韌體版本使用不同原廠元件，快圖會先檢查版本及元件身份。文石入口同樣需要已支援的原廠服務，不能推論適用於所有 BOOX 機型與韌體。已測範圍見 [VALIDATION](VALIDATION.md)。

### 新版 Android 與動畫圖片

快圖支援僅能執行 64 位元 App 的裝置。動畫 WebP 和 GIF 可自動播放，靜態 WebP 照常顯示；關閉圖片轉場也會保留動畫圖片本身的播放。

## 安裝與使用

到 [GitHub Releases](https://github.com/jason840709/QuickPic-Gallery-Mod-2/releases/latest) 下載正式 APK，用手機或平板的檔案管理員點選安裝。首次開啟時，依 Android 提示授予圖片或檔案存取權限，再選擇資料夾開始看圖。

更新本專案的同套件 App 可保留設定。更早的分身使用不同套件，需各自設定。編輯資料夾路徑時，末尾不要加 `/`。
